# Adendo: tratamento de callbacks expirados

> Bug: `BUG-20260924-K7M2`
> Versão: `v001`
> Vigência: vigente desde 2026-09-24
> Veredito aprovado pelo usuário: `spec-gap`

## Seção alvo

Comportamento aditivo à experiência de interação do bot. A extração atual não possuía regra específica para callbacks expirados.

## Regra adicionada

1. Quando o Telegram rejeitar um callback porque sua identificação expirou, a ação associada não deve ser executada.
2. O bot deve enviar uma nova mensagem orientando o usuário a executar `/menu` para obter opções atualizadas, quando o canal de mensagem estiver disponível.
3. Erros de callback que não representem expiração conhecida não devem ser silenciosamente capturados.
4. A política deve ser compartilhada pelos handlers de menu, compras, contas e categorias.
