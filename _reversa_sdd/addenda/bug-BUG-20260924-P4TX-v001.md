# Adendo: operações bloqueantes fora do event loop

> Bug: `BUG-20260924-P4TX`
> Versão: `v001`
> Vigência: vigente desde 2026-09-24
> Veredito aprovado pelo usuário: `spec-gap`

## Seção alvo

Comportamento aditivo aos requisitos não funcionais de desempenho e responsividade do bot.

## Regra adicionada

1. Handlers assíncronos do Telegram não devem executar diretamente operações síncronas de banco, rede ou disco.
2. Chamadas síncronas de `CompraService` e `Database` devem ser delegadas para uma thread ou substituídas por implementação assíncrona equivalente.
3. Uma operação lenta de banco não deve impedir o event loop de processar outra mensagem ou callback.
4. A delegação não deve alterar resultados, regras de negócio, isolamento por usuário ou tratamento de erros.
