#2 · BUG-20260924-P4TX

experiencia-do-bot · high/P1 · 2026-09-24

Causa raiz confirmada

Handlers assíncronos executam métodos síncronos de banco diretamente. Uma operação de 200 ms atrasou um heartbeat de 10 ms para 215 ms.

Estratégia direta

Delegar todas as chamadas síncronas de CompraService feitas nos handlers para asyncio.to_thread. A lógica de negócio e os contratos permanecem inalterados.

CHGTipoArtefatoPropósito
CHG-001testtests/test_bot_responsiveness.pyProvar que o event loop continua responsivo
CHG-002codesrc/telegram/telegram_bot.pyDelegar I/O bloqueante para threads

Pontos cobertos

Listar compras, listar contas, listar categorias, buscar conta, cadastrar conta e categoria, confirmar compra e callbacks equivalentes.

Testes

  • Reprodução: heartbeat não pode esperar a latência do banco.
  • Regressão: resultado do serviço continua sendo usado pelo handler.
  • Suíte completa para estados, callbacks e fluxos financeiros.

Risco

Médio pelo número de pontos tocados. A alteração é mecânica, reversível e não muda banco, dados nem API.

Fora do escopo: retentativas dos provedores de IA.
